# Wear VPN

[English](README.md) · **Русский**

Простой VPN/прокси-клиент для часов на **Wear OS 3+** (Pixel Watch, Galaxy Watch и другие).
Работает с серверами **VLESS** (Xray): tcp, ws, grpc, httpupgrade, xhttp; tls и reality.
Ссылку на **подписку** от VPN-провайдера можно добавить одной командой.

> Личный экспериментальный проект. Проверено на Pixel Watch 4 (Wear OS 6) с подпиской, которая отдаёт ссылки `vless://`.

## Важно знать до установки

На некоторых часах, например на **Pixel Watch 4**, в системе вообще нет сервиса VPN, поэтому настоящий VPN сделать нельзя.
Приложение само определяет это и переходит в **режим прокси**:

| Режим | Когда включается | Что покрывает |
|---|---|---|
| **VPN** | Часы поддерживают системный VPN (например, Galaxy Watch) | Весь трафик часов. *Не проверялся на реальных часах.* |
| **Прокси** | Системного VPN нет (Pixel Watch 4) | Браузер и приложения, которые уважают системный прокси. Остальные его игнорируют. |

В режиме прокси **Telegram** надо настроить отдельно (см. ниже).
Весь трафик, идущий через приложение, **списывается с лимита вашей подписки**.

## Что понадобится

- Часы на Wear OS 3 или новее, подключённые к Wi-Fi (тот же роутер, что и у компьютера).
- Компьютер с Windows, macOS или Linux.
- Программа **adb** (входит в «Android SDK Platform-Tools», бесплатно: <https://developer.android.com/tools/releases/platform-tools>). Распакуйте архив в любую папку, дальше команды запускайте из этой папки.
- Файл **WearVpn-0.1.0-debug.apk** (раздел Releases этого репозитория или самостоятельная сборка, см. внизу).
- Ссылка на вашу подписку или на отдельный сервер `vless://...`.

## Установка по шагам

### 1. Включите отладку на часах

1. На часах: **Настройки → Система → О часах → Версия ПО**, нажмите на **«Номер сборки»** 7 раз, пока не появится сообщение, что вы стали разработчиком.
2. Вернитесь в **Настройки → Параметры разработчика**.
3. Включите **«Отладка по ADB»**, затем **«Отладка по Wi-Fi»**.
4. Откройте экран отладки по Wi-Fi: на нём будет адрес вида `192.168.1.50:34567`.
5. Нажмите **«Подключить новое устройство»**: появятся второй адрес/порт и 6-значный код.

### 2. Подключите часы к компьютеру

В папке с adb выполните (подставьте свои адреса и код):

```
adb pair 192.168.1.50:41234
```
Введите 6-значный код с часов. Затем:

```
adb connect 192.168.1.50:34567
adb devices
```

В списке должны появиться часы со статусом `device`.

> Порт отладки на часах **меняется** после перезагрузки или долгого сна. Если `adb` пишет `offline` или `failed to connect`, откройте экран отладки по Wi-Fi и снова выполните `adb connect` с новым портом.

### 3. Установите приложение

```
adb install -r WearVpn-0.1.0-debug.apk
```

Пока часы не заснули, один раз выдайте приложению право менять системный прокси (нужно для режима прокси):

```
adb shell pm grant com.grsks.wearvpn android.permission.WRITE_SECURE_SETTINGS
```

## Как добавить подписку или сервер

На часах нет удобной клавиатуры, поэтому ссылка передаётся с компьютера.

### Вариант А. Подписка (рекомендуется)

Подписка — это ссылка вида `https://…/sub/…`, которую даёт VPN-провайдер. Выполните:

```
adb shell am broadcast -a com.grsks.wearvpn.SET_LINK -n com.grsks.wearvpn/.LinkReceiver --es link "'https://ВАША-ССЫЛКА-НА-ПОДПИСКУ'"
```

Часы сами скачают список серверов. В ответе вы увидите пронумерованный список:

```
OK выбран [0] NL - Нидерланды
  [0] NL - Нидерланды
  [1] FR - Франция
  [2] DE - Германия
```

Чтобы выбрать другой сервер, добавьте номер: `--ei index 2`:

```
adb shell am broadcast -a com.grsks.wearvpn.SET_LINK -n com.grsks.wearvpn/.LinkReceiver --es link "'https://ВАША-ССЫЛКА-НА-ПОДПИСКУ'" --ei index 2
```

Двойные и одинарные кавычки вокруг ссылки обязательны (внутри ссылки есть символы `&` и `#`).

### Вариант Б. Одиночная ссылка vless://

```
adb shell am broadcast -a com.grsks.wearvpn.SET_LINK -n com.grsks.wearvpn/.LinkReceiver --es link "'vless://...'"
```

### Подписка не подходит?

- В ответе `ERROR В подписке нет серверов vless://…`: часть провайдеров отдаёт серверы только своему приложению (вместо серверов приходит заглушка «App not supported»). Попросите у провайдера «ссылки для других приложений» или отдельные ключи `vless://`. Приложение не притворяется чужим клиентом: обходить ограничения провайдера не стоит.
- Поддерживаются только серверы **VLESS**. Vmess, Trojan, Shadowsocks пока не поддерживаются.

## Использование

1. Откройте на часах приложение **Wear VPN**. На экране будет круглая кнопка и название сервера.
2. Нажмите кнопку: **ВКЛ** (зелёная) значит, что всё работает.
3. Нажмите ещё раз, чтобы выключить. Системный прокси при этом сбрасывается.

**Проверка:** откройте на часах браузер и зайдите на сайт, показывающий ваш IP (например, 2ip.ru). Должен показаться IP сервера, а не ваш домашний.

Держите кнопку включённой только когда нужно: так тратится меньше трафика и батареи.

### Telegram

Telegram не использует системный прокси, у него свои настройки. Приложение открывает для него SOCKS5-прокси:

- Сервер: `127.0.0.1`
- Порт: `10808`
- Логин и пароль: пустые

В Telegram найдите **Настройки → Данные и память → Прокси** (название может отличаться), добавьте SOCKS5 с этими данными и включите его. В версии для Wear OS 2.0.1 ссылка `tg://socks` не открывается, поэтому прокси нужно вводить вручную. Если такого пункта в вашей версии нет, использовать Telegram через этот VPN не получится.

## Частые вопросы

**Расходуется ли трафик подписки?** Да. Всё, что идёт через приложение, считается у провайдера так же, как с телефона. Ключ общий с другими устройствами, лимиты общие.

**Часы перезагрузились, и всё слетело.** Откройте приложение и нажмите кнопку заново. Ссылка сохраняется, повторять команды `adb` не нужно.

**Сайты не открываются, хотя написано ВКЛ.** Нажмите кнопку дважды (выкл, вкл). Если не помогло, смените сервер командой с другим `--ei index`.

**Интернет на часах пропал после удаления приложения.** Сбросьте прокси: `adb shell settings put global http_proxy :0`.

**Приложение не видит разрешения (ошибка про WRITE_SECURE_SETTINGS).** Выполните ещё раз команду `adb shell pm grant …` из шага 3.

**Поддерживается ли IPv6?** Нет, только IPv4.

## Удаление

```
adb shell settings put global http_proxy :0
adb uninstall com.grsks.wearvpn
```

## Сборка из исходников

Нужны JDK 17–21 и Android SDK (подойдёт Android Studio).

```
# 1. Скачать ядро Xray (около 60 МБ, не хранится в репозитории)
mkdir app/libs
curl -L -o app/libs/libv2ray.aar https://github.com/2dust/AndroidLibXrayLite/releases/download/v26.10.31/libv2ray.aar

# 2. Собрать и прогнать тесты
./gradlew assembleDebug testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. На Windows используйте `gradlew.bat` и `Invoke-WebRequest` вместо `curl`.

## Как это устроено

- `VlessConfig` превращает ссылку `vless://` в конфиг Xray (JSON).
- `Subscription` скачивает подписку и достаёт серверы (открытым текстом или base64).
- `XrayVpnService` (режим VPN): Xray читает TUN-интерфейс системного `VpnService`.
- `XrayProxyService` (режим прокси): Xray слушает HTTP `127.0.0.1:10809` и SOCKS5 `127.0.0.1:10808`; HTTP-прокси прописывается в `Settings.Global.http_proxy`.
- `LinkReceiver` принимает ссылку из `adb`.
